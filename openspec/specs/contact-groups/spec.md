# contact-groups Specification

## Purpose

Позволяет пользователю раскладывать знакомых по собственным группам, относить контакт к нескольким кругам общения и находить контакты нужной группы в общем списке.

## Requirements

### Requirement: Пользовательские группы

An authenticated user SHALL be able to view their own groups and create groups with custom names. Group creation MUST NOT require existing contacts. The application MUST persist groups and memberships between visits, including another browser signed into the same account. Groups belonging to other accounts MUST NOT be exposed.

#### Scenario: Создать свою группу
- **WHEN** an authenticated user creates «Теннис»
- **THEN** the group appears in that user's group list and contact selectors
- **AND** the new group has no members

#### Scenario: Создать группу без контактов
- **WHEN** the current user has no contacts and opens group management
- **THEN** the user can create «Семья»

#### Scenario: Открыть в другом браузере
- **WHEN** a user creates groups and assigns contacts, then signs into the same account in another browser
- **THEN** the same group names and memberships are available
- **AND** another account does not receive those groups or memberships

### Requirement: Участники группы

Название каждой группы в разделе «Группы» SHALL быть ссылкой на её отдельную страницу. Страница MUST показывать название и всех участников без повторов, в прежнем порядке контактов, с переходом в карточку каждого. Пустая группа SHALL показывать понятное сообщение; отсутствующая группа SHALL показывать страницу «Не найдено».

#### Scenario: Открыть участников
- **WHEN** пользователь нажимает название группы «Друзья», в которой состоят Анна и Борис
- **THEN** открывается страница «Друзья» с Анной и Борисом по одному разу
- **AND** имя участника открывает его карточку, есть переход обратно ко всем группам

#### Scenario: Пустая или отсутствующая группа
- **WHEN** пользователь открывает существующую группу без участников
- **THEN** видит её название и сообщение об отсутствии участников
- **AND** по адресу несуществующей группы показана страница «Не найдено»

### Requirement: Проверка названия группы

A group name MUST be nonempty after trimming surrounding whitespace, which MUST be removed on save. Creation and renaming MUST reject another group with the same name, ignoring case and surrounding whitespace, only within the current owner's account. On error, the form SHALL explain the problem and preserve the entered name. Different users MUST be allowed to use the same name independently.

#### Scenario: Пустое название
- **WHEN** a user saves a name containing only whitespace
- **THEN** the form says a name is required
- **AND** no group is created or renamed

#### Scenario: Пробелы по краям
- **WHEN** a user creates a group named «  Аналитики  »
- **THEN** it is stored and displayed as «Аналитики»

#### Scenario: Повтор при создании
- **WHEN** the current user already owns «Друзья» and creates « друзья »
- **THEN** the form reports the duplicate
- **AND** no second group is created and the entered name remains in the form

#### Scenario: Повтор при переименовании
- **WHEN** the current user owns «Друзья» and «Теннис» and renames «Теннис» to «ДРУЗЬЯ»
- **THEN** the form reports the duplicate
- **AND** both groups retain their previous names and memberships

#### Scenario: Identical names in different accounts
- **WHEN** A owns «Друзья» and B creates or renames B's group to « друзья »
- **THEN** B's save succeeds with the trimmed name
- **AND** neither user's group exposes or changes the other user's members

### Requirement: Переименование группы

Пользователь SHALL иметь возможность изменить название группы. Переименование MUST сохранять её состав и показывать новое название в управлении группами, выборе групп, карточках контактов и фильтре. Сохранение собственного текущего названия SHALL быть допустимым.

#### Scenario: Изменить название
- **WHEN** пользователь переименовывает группу «Теннис» в «Теннис по выходным»
- **THEN** у всех входивших в неё контактов остаётся эта группа под новым названием
- **AND** новое название доступно в фильтре и форме контакта

#### Scenario: Сохранить прежнее название
- **WHEN** пользователь сохраняет название группы без изменений или меняет только регистр букв её собственного названия
- **THEN** сохранение проходит успешно, если название не совпадает с другой группой

### Requirement: Удаление группы

Удаление группы MUST требовать подтверждения с пояснением, что контакты сохранятся. После подтверждения группа MUST исчезнуть из списка групп, форм, карточек и фильтра. Принадлежность контактов к другим группам, сами контакты, их поля и заметки MUST сохраниться.

#### Scenario: Подтвердить удаление
- **WHEN** пользователь подтверждает удаление группы «Теннис», а контакт Анна входит в «Теннис» и «Друзья»
- **THEN** группа «Теннис» исчезает, Анна остаётся в «Друзья»
- **AND** контакт Анны, его поля и заметки сохранены

#### Scenario: Отменить удаление
- **WHEN** пользователь открывает подтверждение удаления группы и нажимает «Отмена»
- **THEN** группа и её состав остаются прежними

### Requirement: Несколько групп у контакта

В формах добавления и изменения контакта пользователь SHALL иметь возможность выбрать любое количество существующих групп, включая ноль, и снять ранее выбранные группы. Выбор MUST сохраняться по общей кнопке сохранения вместе с остальными полями контакта. Один контакт MUST входить в каждую группу не более одного раза.

#### Scenario: Создать контакт в двух группах
- **WHEN** пользователь добавляет Анну, выбирает «Друзья» и «Теннис» и сохраняет контакт
- **THEN** Анна входит в обе группы

#### Scenario: Изменить состав групп контакта
- **WHEN** пользователь открывает изменение Анны, снимает «Теннис», добавляет «Аналитики» и сохраняет
- **THEN** Анна входит в «Друзья» и «Аналитики», но не входит в «Теннис»

#### Scenario: Контакт без групп
- **WHEN** пользователь сохраняет контакт без выбранных групп или снимает все выбранные группы
- **THEN** контакт успешно сохраняется и доступен в общем списке

#### Scenario: Ошибка в другом поле
- **WHEN** пользователь выбирает группы и сохраняет контакт с ошибкой в другом поле
- **THEN** форма показывает ошибку и сохраняет выбор групп для исправления
- **AND** ни поля контакта, ни его принадлежность к группам не сохраняются частично

#### Scenario: Отмена изменения
- **WHEN** пользователь меняет выбор групп в форме контакта и нажимает «Отмена»
- **THEN** ранее сохранённые группы контакта остаются прежними

### Requirement: Создание группы в форме изменения контакта

Форма изменения контакта SHALL показывать «+» рядом с выбором групп. Кнопка MUST открывать поле названия и создавать группу с немедленным назначением этому контакту, как в карточке. Остальные введённые поля и текущий выбор групп MUST сохраняться в форме. «Отмена» формы контакта SHALL сохранять уже созданную и назначенную группу. Отмена самого ввода новой группы SHALL ничего не создавать.

#### Scenario: Создать группу во время изменения
- **WHEN** пользователь меняет поля контакта и выбор групп, затем создаёт новую группу через «+»
- **THEN** группа сразу создана и назначена контакту, новая отметка выбрана в форме
- **AND** остальные введённые поля и прежние отметки формы сохранены
- **AND** общая кнопка «Сохранить» сохраняет остальные правки, а «Отмена» оставляет уже созданную группу у контакта

#### Scenario: Ошибка названия в форме изменения
- **WHEN** пользователь пытается создать пустое или повторное название через «+»
- **THEN** видит ошибку у поля названия, введённые данные и выбор групп не теряются
- **AND** ошибка не сохраняет остальные изменения контакта

### Requirement: Группы в карточке контакта

Карточка контакта SHALL показывать названия всех назначенных ему групп и кнопку «+», открывающую небольшую форму создания новой группы прямо в карточке. Кнопка MUST быть доступна и у контакта без групп; пустой список групп SHALL не показываться. Созданная здесь группа MUST сразу назначаться этому контакту; создание и назначение MUST сохраняться целиком. Применяются общие проверки названия, ошибка MUST сохранять ввод. Пользователь SHALL оставаться в карточке и иметь возможность отменить создание.

#### Scenario: Показать несколько групп
- **WHEN** пользователь открывает карточку Анны, входящей в «Друзья» и «Теннис»
- **THEN** в карточке видны оба названия

#### Scenario: Нет назначенных групп
- **WHEN** пользователь открывает карточку контакта без групп
- **THEN** карточка доступна, показывает кнопку «+» для создания новой группы и не содержит пустого списка групп

#### Scenario: Создать группу в карточке
- **WHEN** пользователь нажимает «+» рядом с группами в карточке контакта
- **THEN** в карточке открывается поле названия с кнопками «Создать» и «Отмена»
- **AND** кнопка доступна с клавиатуры и имеет доступное название «Создать новую группу»
- **AND** после ввода нового названия и сохранения группа создана, назначена этому контакту и видна в его карточке
- **AND** пользователь остаётся в карточке, остальные группы контакта сохранены

#### Scenario: Отмена создания группы в карточке
- **WHEN** пользователь вводит название в открытой форме и нажимает «Отмена» или Escape
- **THEN** форма закрывается, группа и связь с контактом не создаются

#### Scenario: Ошибка создания или назначения группы в карточке
- **WHEN** название пустое, совпадает с другой группой, контакт уже удалён или запись связи завершается ошибкой
- **THEN** новая группа и связь с контактом не сохраняются частично
- **AND** при ошибке названия форма показывает объяснение и сохраняет введённое название

### Requirement: Фильтр по группе на главной

На главной пользователь SHALL выбирать несколько групп галочками и видеть контакты, входящие хотя бы в одну выбранную группу, без повторов. Без отметок SHALL показываться «Все контакты», включая контакты без групп. Отдельные отметки и весь выбор MUST сниматься. Поиск по имени MUST работать вместе с фильтром, сохраняя прежние правила и порядок контактов. Пустой результат SHALL поясняться сообщением. Стрелка раскрытия MUST иметь отступ от правого края поля.

#### Scenario: Выбрать группу
- **WHEN** Анна входит в «Друзья» и «Теннис», Борис только в «Друзья», и пользователь выбирает «Теннис»
- **THEN** общий список показывает Анну один раз и не показывает Бориса

#### Scenario: Искать внутри группы
- **WHEN** пользователь выбирает «Друзья» и вводит «Анна» в поиск по имени
- **THEN** видны только контакты этой группы, подходящие под поиск

#### Scenario: Вернуться ко всем контактам
- **WHEN** пользователь снимает все галочки или нажимает «Все контакты»
- **THEN** поиск по имени применяется ко всем контактам, включая контакты без групп
- **AND** введённое имя сохраняется

#### Scenario: Объединение нескольких групп
- **WHEN** Анна входит в «Друзья» и «Теннис», Борис только в «Друзья», а Дарья только в «Теннис», и пользователь отмечает обе группы
- **THEN** общий список показывает Анну, Бориса и Дарью по одному разу
- **AND** поиск по имени применяется к этому объединению

#### Scenario: Удаление части выбранных групп
- **WHEN** после обновления данных одна из отмеченных групп удалена
- **THEN** фильтр сохраняет остальные выбранные группы и убирает отсутствующую
- **AND** если ни одной выбранной группы не осталось, показаны «Все контакты» с прежним поисковым запросом

#### Scenario: Пустая группа или нет совпадений
- **WHEN** в выбранной группе нет контактов или ни один не подходит под поиск
- **THEN** показано сообщение об отсутствии подходящих контактов
- **AND** пользователь может изменить поиск или выбрать «Все контакты»

### Requirement: Подписи групп в результатах фильтра

При фильтрации общего списка по группам каждая строка контакта SHALL показывать названия выбранных групп, в которые он входит. Группы вне текущего выбора MUST быть скрыты. Без выбранных групп подписи SHALL не показываться, в том числе при поиске только по имени. Смена галочек и сброс MUST сразу обновлять подписи, сохраняя прежний порядок контактов и работу поиска.

#### Scenario: Несколько выбранных групп
- **WHEN** выбраны «Друзья» и «Теннис», Анна входит в обе и ещё в «Семья», а Борис только в «Друзья»
- **THEN** у Анны показаны «Друзья» и «Теннис», у Бориса — только «Друзья»
- **AND** «Семья» в строке Анны скрыта, каждый контакт показан один раз

#### Scenario: Одна группа или сброс выбора
- **WHEN** пользователь оставляет одну галочку
- **THEN** видимые строки показывают только название этой группы
- **AND** после снятия всех галочек подписи групп скрыты, даже если поиск по имени заполнен

### Requirement: Переход к настройке групп контакта

Под группами в карточке SHALL находиться кнопка «Настроить группы». Она MUST открывать форму изменения этого контакта и прокручивать её к блоку выбора групп, в том числе при прямом открытии ссылки и на узком экране.

#### Scenario: Настроить группы из карточки
- **WHEN** пользователь нажимает «Настроить группы» в карточке Анны
- **THEN** открывается форма изменения Анны, блок групп виден в области экрана
- **AND** обычное редактирование остальных полей остаётся доступным

### Requirement: Совместимость с существующими контактами

После добавления групп существующие контакты MUST оставаться без групп до назначения пользователем, сохраняя свои поля и заметки. Группы MUST не изменять расчёт сроков общения; поиск и фильтр групп MUST влиять только на общий список, сохраняя в блоке «Пора связаться» все просроченные контакты.

#### Scenario: Существующие данные после обновления
- **WHEN** пользователь открывает приложение после обновления с группами
- **THEN** прежние контакты и заметки доступны, контакты не распределены по группам автоматически
- **AND** прежние настройки частоты и сроки общения сохранены

#### Scenario: Фильтр не скрывает просроченные контакты
- **WHEN** пользователь выбирает «Теннис», а просроченный Борис не входит в эту группу
- **THEN** Борис остаётся в блоке «Пора связаться», хотя отсутствует в отфильтрованном общем списке

#### Scenario: Изменение только групп не сдвигает срок
- **WHEN** пользователь меняет только группы контакта с заданной частотой общения
- **THEN** срок следующего общения остаётся прежним
